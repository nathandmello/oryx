# PM Studio

This repository holds your reference material and working files. Start a [protected PM session](../../playbook/overrides.md). Read its [constitution](../../AGENTS.md) and [Git rules](../../playbook/git.md).

Start with [company context](../../playbook/company-context.md). Use [context](context/README.md) to find what is known. Use [workspace](workspace/README.md) to find what is being done.

Use [Studio customizations](../../playbook/overrides.md) to change how oryx works for you.

Keep your background, preferences, and responsibilities together in `context/pm/context.md`. Keep installation settings and remote locations in `settings.json`.

Keep the current session checkpoint and next action here. Use [the working practices](../../playbook/working.md) across sessions.
