# PM Studio

This repository holds your reference material and working files. Start a [protected PM session](../../playbook/overrides.md). Read its [constitution](../../AGENTS.md) and [Git rules](../../playbook/git.md).

Your first request starts [guided setup](../../playbook/company-context.md). Review each topic with oryx. Open questions can carry forward to later work.
Use [context](context/README.md) to find what is known. Use [workspace](workspace/README.md) to find what is being done.

Use [Studio customizations](../../playbook/overrides.md) to change how oryx works for you.

Keep your role, expectations and aspirations in `context/pm/context.md`. Use `context/stakeholders/overview.md` for reporting lines and decision relationships. Keep installation settings and remote locations in `settings.json`.

Keep the current session checkpoint and next action here. Use [the working practices](../../playbook/working.md) across sessions.
