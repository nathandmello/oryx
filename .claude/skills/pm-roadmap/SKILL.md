# Order roadmap outcomes

Use [prioritize-roadmap](../prioritize-roadmap/SKILL.md) for registered initiative comparisons, signed cycle changes, and generated roadmaps.

1. Follow [the session steps](../../../playbook/working.md#run-a-workflow). Read [Iterations](../../../playbook/sources/product-strategy-mindset.md#section-7-iterations).
2. Read the strategy, goals, evidence, and existing commitments. Open the existing record or use the [roadmap template](../../../templates/roadmap.md).
3. State the intended change in customer behaviour or business results. Select a structure from the source that fits the outcome story.
4. Stack-rank outcomes by confidence in their ability to create value. Cite evidence, expected impact, and any constraints that affect order.
5. Keep proposals, commitments, delivery progress, and measured outcomes distinct. Link delivery status to its owner.
6. Record accepted changes with dates and rationale. Preserve relevant rejected options and flag upstream choices that new results challenge.
7. Follow [the checkpoint steps](../../../playbook/working.md#checkpoint). Keep unsettled sequencing choices visible for the PM.
